
# DeviceResourcesApp 📱

O **DeviceResourcesApp** é um aplicativo mobile desenvolvido em React Native com Expo que demonstra a integração e utilização de recursos nativos do dispositivo, como a galeria de imagens e a lista de contatos.

---

## 🚀 Funcionalidades

- 📷 **Seleção de Imagens:** Acesso à galeria do dispositivo com solicitação de permissões e exibição da imagem selecionada.
- 🎴 **Lista de Contatos:** Leitura e exibição dos contatos armazenados no dispositivo (nomes, telefones e e-mails).

---

## 🛠️ Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [`expo-image-picker`](https://docs.expo.dev/versions/latest/sdk/image-picker/)
- [`expo-contacts`](https://docs.expo.dev/versions/latest/sdk/contacts/)

---

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- O aplicativo **Expo Go** instalado no seu celular (iOS ou Android) para testar no dispositivo físico, ou um emulador configurado.
